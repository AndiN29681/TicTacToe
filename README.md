# Tic-Tac-Toe Lernprojekt

## Projektbeschreibung
Dieses Projekt ist ein Lernbeispielfür die Entwicklung einer modernen Webanwendung für das Spiel Tic-Tac-Toe. Es dient dazu, mich mit Claude Code, Git und Vercel vertraut zu machen – und nicht nur funktionierenden Code zu schreiben, sondern auch den gesamten Entwicklungsprozess zu verstehen.

## Technologien
- **Frameworks**: Next.js, React
- **Sprache**: TypeScript
- **Stil**: Tailwind CSS

## Projektziele
1. Lernen durch Bauen: Verstehen, wie ein vollständiges Projekt entsteht
2. Moderne Darstellung: Responsive Design, Barrierefreiheit
3. Gute Entwicklungspraktiken: Saubere Architektur, Git-Nutzung
4. Deployment: Automatisches Deploy mit Vercel

## Struktur
```
src/
├── components/        # UI-Komponenten
├── lib/               # Hilfsfunktionen
├── pages/             # Router-Pages
├── styles/            # Globale Stile
```

## Nächste Schritte
1. Spielmechanik implementieren (3x3 Feld, Spielerwechsel)
2. Zustandmanagement einrichten (Next.js App-Zustand)
3. Design-Coding mit Tailwind
4. Git-Workflow einrichten
5. Vercel-Deployment konfigurieren
